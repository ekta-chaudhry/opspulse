# OpsPulse

OpsPulse is a planned self-hosted reliability platform for monitoring HTTP services and background jobs.

## Status

Only the reproducible TypeScript workspace scaffold is implemented. Product capabilities are not implemented yet.

## Planned Product

The approved product scope includes HTTP and heartbeat monitoring, incident management, webhook notifications, a private operations dashboard, and a public status page.

## Prerequisites

- Node.js 24.18.0
- pnpm 10.30.3
